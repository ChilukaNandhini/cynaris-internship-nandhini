# NumPy Fundamentals – W1D1

## Overview
This folder contains Python programs demonstrating NumPy fundamentals as part of the Cynaris AI/ML internship.

## Programs

| File | Description |
|---|---|
| `numpy_basics.py` | NumPy introduction and basic operations |
| `numpy_arrays.py` | Creating 1D, 2D and 3D arrays and checking shapes |
| `numpy_broadcasting.py` | NumPy broadcasting operations |
| `numpy_vector.py` | Vectorised operations |
| `numpy_multi.py` | Matrix multiplication |
| `numpy_corr.py` | Correlation calculations |
| `statistics.py` | Mean, standard deviation and correlation analysis |

## Dataset
`student_data.csv` contains student-related data:
- `number_courses`: Number of courses opted for
- `time_study`: Average study time
- `Marks`: Marks obtained

## Requirements
- Python 3
- NumPy
- Pandas

Install dependencies:

```bash
pip install numpy pandas
```

## Run the Programs

Run individual scripts from the repository root:

```bash
python numpy_operations/numpy_arrays.py
python numpy_operations/numpy_broadcasting.py
python numpy_operations/statistics.py
```

## Learning Outcomes
- Creating and manipulating NumPy arrays
- Understanding array dimensions and shapes
- Applying broadcasting and vectorisation
- Performing matrix multiplication
- Calculating statistical measures and correlation
